🚀 ¿Cómo Funciona?

1

Clona el Repositorio

Obtén el código fuente completo desde GitHub

git clone https://github.com/agmelendez/webomipyme.git cd webomipyme
2

Instala Dependencias

Configura el entorno de desarrollo para cada componente

# Frontend cd frontend && npm install # API cd api && pip install -r requirements.txt # Dashboards cd dashboards && Rscript setup.R
3

Configura Variables de Entorno

Crea archivos .env con las credenciales necesarias

# frontend/.env.local NEXT_PUBLIC_API_URL=http://localhost:8000 NEXT_PUBLIC_WP_URL=http://localhost:8080 # api/.env DATABASE_URL=postgresql://user:pass@localhost/omipyme
4

Inicia los Servicios

Levanta todos los componentes con Docker Compose

docker-compose up -d # O manualmente cada servicio: # Frontend: npm run dev (http://localhost:3000) # API: uvicorn app.main:app --reload # WordPress: docker-compose up wordpress # Dashboards: Rscript app.R
5

Explora la Plataforma

Navega por los 5 pilares y prueba las funcionalidades

Frontend: localhost:3000 API Docs: localhost:8000/docs WordPress: localhost:8080 Shiny: localhost:3838
